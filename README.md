## About This Repository

This repository contains a comprehensive collection of data-driven football analytics projects completed as part of the **Twelve Soccermatics Pro** course. Each project demonstrates advanced techniques in sports analytics, machine learning, and data visualization applied to real-world football data.

The course, led by industry experts, focuses on transforming raw football data into actionable insights through statistical analysis, predictive modeling, and compelling visual storytelling.

### [Project 2: Expected Danger Model](project_2/)

**Objective:** *Quantifying Pass Danger Through Machine Learning*

A dual-model machine learning system that predicts the offensive value of passes in Premier League football.

#### 🔑 Key Features
- **Two-Model Architecture**: Classification + Regression framework
- **17 Feature Engineering**: Spatial, temporal, and tactical metrics
- **SHAP Interpretability**: Model transparency and feature importance
- **3D Visualizations**: Team-specific danger surface mapping

#### 📊 Technologies
`Python` • `scikit-learn` • `SHAP` • `Plotly` • `Jupyter Notebook`

#### 🚀 Highlights
- Achieved **0.7639 AUC** on shot prediction
- Analyzed **Premier League 2023-24** full season
- Created **20 team-specific 3D danger surfaces**
- Identified distance to goal as dominant predictor

**[📂 View Project](project_2/)** | **[📓 View Notebook](project_2/Expected_Danger_Model.ipynb)**

## Technical Stack

This portfolio leverages a modern data science and analytics stack:

### Data & Analysis
- **Data Sources**: StatsBomb Open Data, Twelve Football datasets
- **Processing**: Pandas, NumPy
- **Machine Learning**: scikit-learn
- **Model Interpretation**: SHAP (SHapley Additive exPlanations)

### Visualization
- **Static Plots**: Matplotlib, Seaborn, mplsoccer
- **Interactive Charts**: Plotly
- **3D Surfaces**: Plotly 3D scatter/surface plots
- **Dashboards**: Streamlit

### Development
- **Languages**: Python 3.8+
- **Notebooks**: Jupyter Notebook
- **Version Control**: Git
- **Deployment**: Streamlit Cloud
